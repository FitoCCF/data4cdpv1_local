# data4cdpv1_local

Scripts Python aislados. Banco de pruebas local de ../data4cdpv1/.

## Regla
Lo que se prueba aquí debe llegar a data4cdpv1/ con la misma versión de
dependencias (Pixi). Si divergen, es un bug esperando.

## Convenciones
- Estructura OOP para adquisición, con manejo explícito de dev/prod.
